
# MultiStepForm

A basic project showcasing how you can design your sign-up and login form in a multi-step way.

## About MultiStepForm
This project demonstrates how to create multi-step sign-up and login forms. It was initially designed in 2023 and uploaded on GitHub on February 29, 2024.

## Features
- Multi-step form for sign-up and login
- Responsive design
- Clean and modern layout
- Easy to customize

## Installation
1. Clone the repository
   ```bash
   git clone https://github.com/czDamian/MultiStepForm.git
   ```
2. Navigate to the project directory
   ```bash
   cd MultiStepForm
   ```
3. Open `index.html` in your browser

## Usage
1. **Sign-Up Form**: Follow the multi-step process to create a new account.
2. **Login Form**: Use the multi-step login form to access your account.
3. Customize the content in `index.html` and the styles in `styles.css` to fit your needs.
